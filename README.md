# vk-bot-mg

VK-бот для сбора заявок в «Молодую Гвардию». Задаёт пользователю ряд вопросов, сохраняет ответы в базу данных, а также рассылает уведомления о мероприятиях.

## Стек

- Python 3.12.0
- vk-api — работа с VK LongPoll
- SQLite — хранение заявок
- cryptography — шифрование персональных данных
- loguru — структурированное логирование

## Быстрый старт

### 1. Зависимости

```bash
uv sync
```

### 2. Конфигурация

Скопируйте `config.example.json` в `config.json` и заполните нужные поля:

```json
{
    "vk_token": "your_vk_token_here",
    "session_timeout": 600,
    "db_path": "quiz.db",
    "key_path": "secret.key",
    "log_level": "INFO",
    "log_format": "text",
    "admin_ids": [123456789],
    "group_id": 123456789,
    "event_links": [
        "Ссылка на чат 1: https://vk.me/join/XXXXX"
    ],
    "broadcast_tag": "#мероприятие"
}
```

### 3. Запуск

```bash
task run
# или напрямую
uv run python src/main.py
```

## Задачи (Taskfile)

| Команда | Описание |
|---|---|
| `task` | Установить зависимости и запустить бота |
| `task run` | Запустить бота |
| `task sync` | Установить зависимости |
| `task seed` | Наполнить БД тестовыми данными |
| `task clean` | Удалить все `__pycache__` |

## Возможности

- **Анкета** — пошаговый опрос с валидацией ввода; повторные заявки блокируются.
- **Шифрование** — персональные данные хранятся в зашифрованном виде.
- **Broadcaster** — фоновый поток следит за стеной группы; при появлении поста с `broadcast_tag` рассылает уведомление всем зарегистрированным пользователям с RSVP-вопросом.
- **Админ-панель** — команды (префикс `/`) для просмотра статистики и управления базой.
- **Сессии** — неактивные сессии истекают по таймауту.

## Структура проекта

```
config.json          — конфигурация
seed/
  seed.py            — генерация тестовых данных
src/
  main.py            — точка входа
  config.py          — загрузка конфигурации из config.json
  bot/
    bot.py           — логика бота, обработка шагов анкеты и RSVP
    broadcaster.py   — рассылка уведомлений о мероприятиях
    vk_client.py     — обёртка над VK API и LongPoll
  database/
    database.py      — работа с SQLite
  models/
    quiz.py          — модели анкеты, шаги опроса, сессии
  security/
    encryptor.py     — шифрование данных
  validation/
    validator.py     — валидация ответов пользователя
```

## Администрирование

Управление ботом происходит через личные сообщения ВКонтакте. Администраторы задаются двумя способами: статически — через поле `admin_ids` в `config.json` (суперадмины), и динамически — командой `/addadmin`.

Суперадминов нельзя удалить командой `/removeadmin` — только вручную через конфиг.

### Команды

| Команда | Описание |
|---|---|
| `/help` | Список доступных команд |
| `/stats` | Статистика по заявкам: общее количество, средний возраст, топ городов/регионов, распределение по образованию и членству в ЕР |
| `/addadmin <vk_id>` | Добавить пользователя в администраторы |
| `/removeadmin <vk_id>` | Удалить администратора (кроме суперадминов) |
| `/admins` | Список текущих администраторов |
