# МГЕР40: VK-бот для рассылок

Бот принимает заявки на вступление в «Молодую Гвардию» через личные сообщения ВКонтакте. Задаёт пользователю вопросы по шагам, проверяет введённые данные, сохраняет анкету в базу. Отдельным фоновым процессом следит за стеной группы и при появлении нового поста с нужным тегом рассылает уведомление всем участникам.

## Установка

### Python и uv

Для работы нужен Python 3.12.0. Зависимости устанавливаются через [uv](https://docs.astral.sh/uv/) — быстрый пакетный менеджер для Python.

Установка uv (выполнить один раз):

```bash
# macOS / Linux
curl -LsSf https://astral.sh/uv/install.sh | sh

# Windows (PowerShell)
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```

После установки uv перейдите в папку проекта и установите зависимости:

```bash
uv sync
```

Это создаст виртуальное окружение `.venv` и установит все нужные пакеты.

### make

`make` нужен для удобного запуска через `Makefile`.

```bash
# Ubuntu / Debian
sudo apt install make

# macOS (через Homebrew)
brew install make

# Windows — установить через Chocolatey
choco install make
# или через Scoop
scoop install make
```

## Конфигурация

Все настройки хранятся в файле `config.json` в корне проекта. Создайте его перед первым запуском.

```json
{
    "vk_token": "vk1.a.ВАШ_ТОКЕН",
    "group_id": 123456789,
    "admin_ids": [123456789],
    "db_path": "quiz.db",
    "key_path": "secret.key",
    "broadcast_tag": "#мероприятие",
    "session_timeout": 600,
    "reconnect_delay": 5,
    "log_level": "INFO"
}
```

Что означает каждое поле:

**`vk_token`** — токен сообщества ВКонтакте. Получить можно в настройках группы: «Работа с API» → «Создать ключ доступа». Нужны права на сообщения и стену.

**`group_id`** — числовой идентификатор группы ВКонтакте. Можно найти в адресной строке или через `vk.com/club<id>`.

**`admin_ids`** — список VK ID суперадминистраторов через запятую. Эти пользователи имеют доступ к командам управления ботом сразу после запуска. Суперадминов нельзя удалить через бота, только вручную из этого файла.

**`db_path`** — путь к файлу базы данных SQLite. При первом запуске создаётся автоматически. Можно указать абсолютный путь или оставить `"quiz.db"` - тогда файл появится в папке проекта.

**`key_path`** — путь к файлу с ключом шифрования. При первом запуске ключ генерируется и сохраняется туда. Персональные данные в базе хранятся в зашифрованном виде — если потерять этот файл, прочитать анкеты будет невозможно. Храните его в безопасном месте.

**`broadcast_tag`** — хэштег, по которому бот определяет «мероприятийный» пост на стене группы. Как только появляется пост с этим тегом, всем зарегистрированным участникам уходит уведомление с вопросом «пойдёте?».

**`session_timeout`** — время в секундах, в течение которого пользователь должен заполнить анкету. По истечении сессия сбрасывается и нужно начинать заново. По умолчанию 600 (10 минут).

**`reconnect_delay`** — пауза в секундах перед повторным подключением при обрыве связи с VK. По умолчанию 5.

**`log_level`** — уровень логирования: `DEBUG`, `INFO`, `WARNING`, `ERROR`. Для боевого режима достаточно `INFO`.

## Запуск

```bash
# Через make
make run

# Напрямую
uv run python src/main.py
```

Бот запустится и будет слушать входящие сообщения. Чтобы остановить, нажмите `Ctrl+C`.

Другие команды make:

```bash
make seed    # заполнить базу тестовыми данными
make clean   # удалить кэш Python (__pycache__)
```

## Возможности

Анкета запускается, когда пользователь присылает боту сообщение «вступить», «заявка» или `/start`. Бот задаёт вопросы по очереди: ФИО, дата рождения, регион, город, телефон, email/Telegram, уровень образования, членство в партии, предыдущие организации, место учёбы или работы. Каждый ответ проверяется — если формат неверный, бот просит ввести заново. Повторная подача заявки с того же аккаунта блокируется.

Рассылка работает в фоновом потоке. Бот периодически проверяет стену группы, и если находит пост с тегом `broadcast_tag`, отправляет всем участникам текст поста и ссылки на чаты с вопросом «Придёте на мероприятие? (да/нет)». Ответ сохраняется.

## Администрирование

Управление ботом происходит через личные сообщения ВКонтакте — никакого внешнего интерфейса не нужно. Достаточно написать боту нужную команду с аккаунта администратора.

Администраторов двух видов. Суперадмины прописаны в `config.json` в поле `admin_ids` — они активны сразу при запуске и удалить их через бота нельзя. Обычные администраторы добавляются и удаляются командами прямо в переписке.

### Команды

**`/помощь`** — выводит список всех доступных команд с кратким описанием.

**`/статистика`** — показывает сводку по заявкам: общее количество, средний возраст участников, топ городов и регионов, распределение по уровню образования и членству в «Единой России».

**`/добавить_админа <vk_id>`** — добавляет пользователя в администраторы. После этого он получает доступ ко всем командам. Пример: `/добавить_админа 123456`.

**`/удалить_админа <vk_id>`** — снимает права администратора. Суперадминов из `config.json` таким образом удалить нельзя. Пример: `/удалить_админа 123456`.

**`/админы`** — список всех текущих администраторов (VK ID).

**`/ссылки_для_рассылок`** — показывает ссылки на чаты, которые прикрепляются к каждому уведомлению о мероприятии.

**`/добавить_ссылку <текст>`** — добавляет новую ссылку в список рассылки. Текст может быть любым, например: `/добавить_ссылку Чат мероприятия: https://vk.me/join/XXXXX`.

**`/удалить_ссылку <N>`** — удаляет ссылку по её порядковому номеру из списка `/ссылки_для_рассылок`. Пример: `/удалить_ссылку 2`.
